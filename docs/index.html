Multiple Regression Explorer

A CRISP-DM study of model selection and parsimony, extended to accept any CSV. OLS, Lasso and ElasticNet coordinate descent, the t and F distributions, VIF and the scikit-learn-compatible train/test split are all implemented in plain JavaScript — no server, no Python runtime, nothing precomputed.
